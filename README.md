Construct Portal

Construct Portal — веб-приложение для просмотра новостей и вакансий, а также управления контентом через административную панель.

📌 Версия

1.0

📖 Описание

Construct Portal предназначен для пользователей, интересующихся новостями и вакансиями, а также для администраторов, которые управляют публикациями.

Функционал разделён по ролям:

Гости — просмотр новостей и вакансий

Пользователи — регистрация и авторизация

Администраторы — управление новостями и вакансиями

🚀 Возможности

Просмотр новостей по категориям

Просмотр вакансий по категориям

Поиск новостей и вакансий

Регистрация и авторизация пользователей

Управление учетной записью

Добавление / редактирование / удаление новостей (Admin)

Добавление / редактирование / удаление вакансий (Admin)

🔧 Установка и запуск

Клонировать репозиторий:

git clone https://github.com/your-username/construct-portal.git


Перейти в папку проекта:

cd construct-portal


Запустить локальный сервер (например, через OpenServer / XAMPP / встроенный сервер):

http://localhost/ConstructPortal


⚠️ Убедитесь, что веб-сервер и база данных запущены.
